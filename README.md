# Cube 2: Sauerbraten // Browser Hub 🚀

A fast, lightweight, and completely open-source single-page static arcade and educational hub for the legendary 3D arena shooter **Cube 2: Sauerbraten**. 

Play the game instantly in your browser via WebGL2/WebAssembly, learn real-time cooperative map editing shortcuts, and access essential server commands.

## 🎮 Features

- **Inline WebGL2 Client:** Play instantly via an embedded, fully responsive HTML5 game canvas (powered by open-source community ports).
- **Fullscreen API Integration:** Tap the "Go Fullscreen" button to automatically lock your mouse pointer for seamless, desktop-grade aim precision.
- **Interactive Cheat Sheets:** Quick-reference tables detailing layout shortcuts for Cube 2's famous real-time map editing engine.
- **Server Command Terminal:** A code-styled cheat sheet container mapping master modes, map loading commands, and client configurations.
- **Static & Fast:** Zero framework dependencies, zero databases, and zero tracking. Crafted purely with vanilla HTML5, CSS3, and JavaScript.

## 🕹️ How to Play

1. Scroll to the **Browser Hub** section.
2. Click anywhere inside the game window to capture your mouse (**Pointer Lock**).
3. **Controls:**
   - `W, A, S, D` or `Arrow Keys` — Move
   - `Mouse` — Look & Aim
   - `Left Click` — Shoot
   - `Spacebar` — Jump
   - `1 to 9` / `Scroll Wheel` — Change Weapons
4. Press **`ESC`** at any time to release your mouse cursor.

## 🛠️ Map Editing Basics

Cube 2 features a fully integrated, cooperative 3D map editor. To start creating:
- Press **`E`** or **`Ctrl + E`** to toggle **Edit Mode**.
- Open the terminal key (`/`) and type `/newmap` to generate a blank canvas grid.
- Hover your cursor over a grid cube and **Scroll your Mouse Wheel** to push or pull 3D geometry instantly.
- Type `/savemap [name]` to save your level data layout.

## 🚀 Hosting This Yourself (Free & Fast)

Since this project is entirely static, you can host it for free on **GitHub Pages** in under 60 seconds:

1. **Fork or Download** this repository.
2. Go to your repository's **Settings** tab on GitHub.
3. Select **Pages** from the left sidebar navigation menu.
4. Under *Build and deployment*, set the Source branch to **`main`** (or `master`) and directory folder to **`/root`**.
5. Hit **Save**. GitHub will instantly generate your public live arcade URL!
